# The tutorial game made in the minicourse of gamedevelopment of CAJUFPR
This game is a simple platform game, made to teach the fundations of gamedev and Godot engine.

## Prerequisites

To run this project locally, you will need:

* **[Godot Engine](https://godotengine.org/download/)** (Version `4.7`)
* **[Git](https://git-scm.com/downloads)** *(optional, if you prefer cloning the repository via terminal)*

---

## How to Download and Install

You can get the source code in two ways: by cloning the repository via terminal or downloading it as a `.zip` file directly from GitHub.

### Option 1: Via Git Clone (Recommended)

1. Open your terminal (Linux/macOS) or Git Bash/Command Prompt (Windows).
2. Clone this repository using the command below:
   ```bash
   git clone [https://github.com/sergingameprays/minicourse_game-2026.2.git](https://github.com/sergingameprays/minicourse_game-2026.2.git)

    Navigate into the project directory:
    Bash

    cd minicourse_game-2026.2

### Option 2: Via .zip Download

1. At the top of this GitHub repository page, click the green <> Code button.
2. Select Download ZIP.
3. Extract the downloaded .zip file to a folder of your choice on your computer.

## Opening and Running in Godot

1. Launch the Godot Engine (Project Manager).

2. In the top-left corner, click Import.

3. Browse to the folder where you cloned or extracted the repository and select the project.godot file.

4. Click Import & Edit.

5. Wait for Godot to finish importing the project assets (textures, audio, and scenes) for the first time.

6. Press F5 (or click the Play icon in the top-right corner of the editor) to start the game.
